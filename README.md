# BeatPad 🥁

BeatPad is an interactive drum pad web application that allows users to create beats by triggering different sounds through clickable pads. It provides a simple and engaging way to experiment with rhythm and sound directly in the browser.

## Features
- Interactive drum pads.
- Play different sounds by clicking the pads.
- Responsive and user-friendly interface.
- Real-time sound playback.

## Technologies Used
- HTML5
- CSS3
- JavaScript
